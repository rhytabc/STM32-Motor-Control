# 力反馈旋钮（弹簧手感）

基于 2804 无刷电机 + SimpleFOC，把电机变成一个"会自动回中"的旋钮——拧它，它弹回；松手，它停在中间。

这是前面所有内容的综合应用：**力矩控制 + 编码器反馈 + FOC**。

## 硬件

与 [无刷电机项目](../2-BLDC-SimpleFOC/) 完全相同，无需额外硬件。

## 原理

```
编码器读当前角度
    ↓
力 = -K × (当前角度 - 中心角度)
    ↓
电机输出这个力（反向顶你）
```

核心就一行：

```cpp
float torque = -spring_K * (angle - center_angle);
motor.move(torque);
```

- `spring_K` 是弹簧刚度：越大越硬，越小越软
- `center_angle` 是回中点

## 串口命令

| 命令 | 功能 |
|---|---|
| `K20` | 设置弹簧刚度（越大越硬） |
| `Z` | 把当前位置设为回中点 |

## 体验

1. 烧录后，电机上电位置自动设为回中点
2. 用手拧电机外壳 → 松手 → 弹回中间
3. 发 `K2` 感受软弹簧，发 `K20` 感受硬弹簧

## 扩展方向

在弹簧力公式基础上，可以模拟更多手感：

| 手感 | 公式 |
|---|---|
| 弹簧 | `-K × (angle - center)` |
| 阻尼 | `-D × velocity` |
| 咔哒 | 在固定角度加"台阶力" |
| 撞墙 | 超过角度限制就顶死 |

这些是汽车旋钮、游戏手柄、高端音响旋钮的核心技术。
